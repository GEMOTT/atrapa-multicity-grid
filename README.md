# ATRAPA Multicity Grid


## Overview

This repository develops a harmonised spatial grid for multicity
analyses within the **ATRAPA (The Active Travel Backlash Paradox)**
project.

The grid provides a common spatial framework for:

- population density
- urban centrality
- cycling infrastructure change
- density × centrality stratification

It supports both **multicity OSM validation** and the development of
**iBESTI**.

## Study cities

- Barcelona
- Paris
- Milan
- Warsaw
- Utrecht
- Malmö
- Ljubljana
