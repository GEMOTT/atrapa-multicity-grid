# ATRAPA Multicity Grid


## Overview

This repository prepares a harmonised **100 × 100 m population grid**
for multicity analyses within the **ATRAPA** project.

The grid is derived from the **JRC-ESTAT Census Population Grid 2021**,
developed by the European Commission Joint Research Centre (JRC) and
Eurostat.

The harmonised grid provides a common spatial backbone for deriving and
integrating:

- population density
- urban centrality
- cycling infrastructure change
- density × centrality strata

It supports the **multicity validation of OpenStreetMap cycling
infrastructure change** and the subsequent development of **iBESTI**.

As an additional diagnostic check, the JRC-ESTAT 100 m population
estimates are compared with official 2021 national 100 m population
grids for Utrecht and Ljubljana.
